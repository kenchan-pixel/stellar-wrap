# 產品需求文件｜Stellar Warp Explorer

## 1. 產品願景

建立一個手機優先、沉浸式、流暢的星際旅行模擬器。使用者不只觀看曲速特效，而是能夠：

1. 在星圖了解自己所處位置。
2. 選擇具方向與距離差異的目的地。
3. 觀看系統自動規劃直航或多段曲速航程。
4. 感受轉向、加速、進入曲速、巡航、脫離曲速與接近目的地的完整連續旅程。
5. 抵達具獨特 3D 天文景觀的星區並進行觀察。
6. 隨版本演進，逐步形成可探索、可發現、可記錄的星際世界。

## 2. 最終使用效果

使用者以手機直向操作為主。主畫面維持乾淨，航行提示集中邊緣；星圖及設定放在可收起控制面板。選定目的地後，只需按一次「啟動航行」，其後系統自動完成全部航段。

旅程必須同時傳達：

- **方向感：** 飛船按星圖實際 3D 方位轉向；中途站續航前重新對準下一段。
- **距離感：** 較遠航段具有較長曲速巡航時間；接近星體時景觀連續放大。
- **空間感：** 星體、環、星雲、小行星及人工設施具有前後深度。
- **地方感：** 不同目的地不是換背景色，而是具有可辨認的天文景觀與環境聲。
- **流暢感：** 脫離曲速後持續向前，平滑減速、定速接近，再於停點煞停；不得出現停頓後突然前移。

## 3. 目標使用者

- 喜歡太空、科幻及沉浸式網頁體驗的手機使用者
- 想快速體驗星際旅行而不想學習複雜駕駛操作的人
- 用作互動展示、概念驗證或後續星際探索產品的基礎

## 4. V4.0 已批准範圍

### 4.1 星圖與導航

- 8 個固定星區，每站具 `X / Y / Z` 模擬座標
- 顯示目前位置、選定目的地及已到訪位置
- 單次安全曲速距離上限：6.0 LY
- 自動建立可通行航線網絡
- 使用 Dijkstra 演算法計算總距離最短路徑
- 顯示每段距離、方位角 `AZ`、高度角 `EL` 及預計時間
- 航行中飛船標記沿星圖航線同步移動

### 4.2 自動航程

每段必須包含：

1. 按實際方向平滑轉向
2. 亞光速加速
3. 進入曲速
4. 曲速巡航
5. 脫離曲速
6. 連續減速
7. 定速向前接近
8. 最後煞停／掠過

多段航行：

- 抵達中途站後短暫飛掠
- 按下一站實際方向重新轉向
- 自動開始下一段
- 最終目的地進入到站探索

### 4.3 星區景觀

- 地球近軌：地球、雲層、城市夜光、月球及軌道環
- 月環基地：月面、遠方地球及軌道基地
- 織女星門：藍白主星與雙層曲速星門
- 天鵝航標：藍紫雙星及立體航標陣列
- 獵戶前哨：紅超巨星、岩質前哨及發射星雲
- 金牛塵海：環狀氣態巨行星、衛星及粉紫塵海
- 天狼中繼站：藍白雙星、冰質小行星及中繼環站
- 比鄰星港：紅矮星、熔岩行星、小行星帶及星港

### 4.4 到站探索

- 中途站顯示簡短飛掠資料並自動續航
- 可按「立即繼續」略過剩餘飛掠時間
- 最終目的地自動緩慢環繞
- 使用者可拖動畫面觀察
- 可暫停自動環繞及重新開啟星圖

### 4.5 聲音及效能

- 程序化 Web Audio 引擎、曲速、轉向、抵達及環境聲
- 音量及靜音控制
- 自動、流暢、標準及高畫質模式
- 自動量度幀時間並調整 DPR、星數、曲速粒子及隧道環數
- 效能調節不得改變航行時間與動畫速度
- 可顯示 FPS、DPR、粒子、Draw Call 及三角形數量

## 5. 硬性要求

- 所有後續要求均為累積修正，不可只完成最新一項而刪除舊功能。
- 手機直向畫面必須可完整操作。
- 主航行視野不得被大段提示文字遮擋。
- 星圖方向、畫面轉向及中途站續航方向必須一致。
- 航行時間必須與段距離有明確關係。
- 最終到站景觀必須與目的地設定相符。
- 60 Hz 流暢度優先於粒子密度與渲染解像度。
- 穩定版本必須保留為不可覆寫快照。

## 6. 非本階段目標

以下功能不應在核心旅行體驗未完成驗證前加入：

- 戰鬥、武器或敵人
- 複雜資源管理、燃料經濟或大型技能樹
- 大量程序生成但缺乏地方特色的星區
- 多人連線
- 帳戶、後端、支付或分析追蹤
- 為桌面而犧牲手機體驗的駕駛艙 UI

## 7. 成功指標

### 體驗

- 初次使用者可在 30 秒內完成選站及啟航
- 無需人手介入即可完成最遠多段航程
- 使用者能從畫面辨認至少 6 個目的地的主要景觀
- 轉向、曲速進入、曲速脫離及抵達沒有可見跳接

### 效能

- 目標手機在自動畫質下，大部分航程接近 60 fps
- 幀率下降時，系統先降低 DPR／粒子／細節，而非降低動畫時間步進
- 沒有長時間主執行緒停頓、明顯熱失控或記憶體持續增加

### 工程

- `npm run check` 通過
- V4.0 穩定版 SHA-256 維持不變
- 任何改動均有清楚測試證據及人手核實項目

## 8. 長期產品方向

在保持低維護架構下，逐步加入：

- 星區觀測點、可發現天文現象及探索紀錄
- 已到訪星區圖鑑與旅行日誌
- 更大的星圖、不同航路特性與可選中途站
- 更具物理與尺度一致性的星體系統
- 輕量任務、研究及攝影目標
- 離線／PWA 支援及可安裝手機體驗
