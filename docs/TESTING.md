# 測試與驗收

## 1. 自動檢查

```bash
npm run check
```

目前檢查：

- 必要檔案存在
- `index.html` 與 V4.0 穩定快照完全一致
- V4.0 穩定版 SHA-256 正確
- HTML 內 module JavaScript 可通過 `node --check`
- Three.js 版本固定為 `0.185.1`
- 八個星區 ID 全部存在且只出現一次於資料定義
- 主要航行狀態全部存在
- 連續抵達函式與 Hermite profile 存在
- 畫質、聲音、探索及星圖功能標記存在
- repo 內沒有常見 API key／私鑰格式
- archive 及 release 清單與已知 hash 相符

自動檢查只證明結構、語法及基線沒有被意外破壞，不能取代 WebGL 視覺及手機實機驗收。

## 2. 核心手動驗收

### A. 啟動與手機 UI

- [ ] iPhone Safari 直向可完整載入
- [ ] HUD 不遮擋中央主視野
- [ ] 星圖面板可開啟、捲動及收起
- [ ] 安全區避開瀏海、Home Indicator
- [ ] 控制按鈕最少約 44 px 可點範圍
- [ ] 首次未互動時沒有自動播放聲音錯誤

### B. 星圖與規劃

- [ ] 顯示目前位置 SOL
- [ ] 可選擇 7 個其他目的地
- [ ] 路線顯示站名、段數、總距離、AZ、EL、時間
- [ ] `SOL → ORION` 規劃為 `SOL → LUNA → VEGA → CYG → ORION`
- [ ] `SOL → TAU` 規劃為 `SOL → SIRIUS → TAU`
- [ ] 航行中飛船圖示沿正確航段移動
- [ ] 已完成航段與目前航段顯示不同狀態

### C. 航行狀態

- [ ] 起航前按實際方向平滑轉向
- [ ] 大幅度轉向沒有跳畫面、抖動或突然反向
- [ ] 亞光速加速可見
- [ ] 進入曲速有星線爆發、光暈、FOV 及隧道建立
- [ ] 曲速巡航長度隨航段距離改變
- [ ] 脫離曲速有收束效果
- [ ] 減速後仍持續向前
- [ ] 接近階段先定速前進，再於終點煞停
- [ ] 三個抵達階段交界沒有停頓後突然前移
- [ ] 航程提示只在畫面邊緣，不阻擋地標

### D. 多段航行

- [ ] 中途站先完成抵達與短暫飛掠
- [ ] 中途地標與站點設定相符
- [ ] 下一段開始前按新座標方向重新轉向
- [ ] 轉向時上一站景觀自然掠出視野
- [ ] 可按「立即繼續」而不破壞下一段
- [ ] 最遠目的地可全自動完成，不需重新按啟動

### E. 目的地景觀

- [ ] SOL：地球海陸、雲層、大氣、城市夜光及月球可辨認
- [ ] LUNA：月面與遠方地球有深度差
- [ ] VEGA：藍白主星及雙層星門可辨認
- [ ] CYG：雙星及航標陣列可辨認
- [ ] ORION：紅巨星、岩質前哨及星雲可辨認
- [ ] TAU：巨型環行星、行星環及塵海可辨認
- [ ] SIRIUS：雙星、中繼環站及冰質物體可辨認
- [ ] PROX：紅矮星、熔岩行星、小行星帶及星港可辨認

### F. 到站探索

- [ ] 最終站自動進入探索模式
- [ ] 自動環繞速度舒適

### G. 聲音

- [ ] 首次按啟動或聲音按鈕後才建立音訊
- [ ] 加速、曲速進入、巡航、脫離及抵達有不同聲音狀態
- [ ] 轉向時聲場左右移動合理
- [ ] 不同星區環境音有差異

### I. 中止與恢復

## 3. 建議測試航線

| 航線 | 目的 |
|---|---|
| SOL → LUNA | 最短直航、細角度轉向、地月景觀 |
| SOL → PROX | 明顯下降高度角、紅矮星與熔岩景觀 |
| SOL → TAU | 南向多段、SIRIUS 中途轉向、環行星終點 |
| SOL → ORION | 最長多段、三次中途轉向、重型星雲場景 |
| ORION → TAU | 大方向改變及網絡跨區路線 |
| TAU → LUNA | 多段返回內圈，測試已到訪狀態 |

## 4. Pull Request 完成標準

每個 PR 必須列明：

- 改變了甚麼使用效果
- 是否影響 V4.0 已批准功能
- 修改的航行階段／星區／資料格式
- 自動測試輸出
- 已完成的手動測試航線及裝置
- 未能自動證明的風險
- 需擁有人手確認的畫面或產品決定

沒有實機證據時，不可聲稱「已穩定 60 fps」；只可說明程式以 60 Hz 為目標及自動調節已通過結構驗證。
