# Visual reference assets

These compressed WebP previews document the approved visual direction and historical V3 scene studies. They are documentation assets only, not runtime dependencies.

| File | Purpose |
|---|---|
| `v3-mobile-idle.webp` | Mobile portrait framing and unobtrusive HUD reference |
| `v3-vega-gate.webp` | Vega gate scene reference |
| `v3-orion-outpost.webp` | Orion red-giant and nebula reference |
| `v3-tau-dust-sea.webp` | Ringed-planet and dust-sea reference |
| `v3-proxima-port.webp` | Red-dwarf and lava-world reference |
| `v3-flight-state-machine.webp` | Earlier flight-state-machine visual reference |
| `earth-render-study.webp` | Procedural Earth material study |

All previews use WebP compression; the Tau and Vega portrait references use compact review thumbnails to keep the repository lightweight.

The executable V4 code remains the source of truth for current behaviour. These previews are compressed and may not match later rendering changes pixel-for-pixel.
