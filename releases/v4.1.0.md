## Included in v4.1.0

- Mobile WebGL context-loss pause and automatic recovery.
- Local travel journal with route, active travel time, distance and cumulative LY.
- LUNA three-point guided observation survey with local discovery persistence.
- Destination Photo Mode with local PNG capture.
- Offline relaunch after one successful online load, plus startup recovery guidance.
- Static navigation fallback when WebGL or 3D startup is unavailable.
- Arrival Debrief with route, legs, distance and active travel time.
- Journey-distance continuity using the core route planner as the single runtime coordinate/distance authority.
