## Why this is v5.0.0

V5 marks the point where Stellar Wrap is no longer only a complete warp-travel simulator with a few destination utilities. The merged product now has a coherent exploration layer across the existing star network, persistent journey/discovery continuity, scenery-first mobile exploration UI, richer in-flight presentation, and a capture workflow designed around destinations worth revisiting and recording.

## Included in v5.0.0

### Exploration layer

- Seven external-system discovery collection with Star Atlas aggregation and completion milestone.
- Destination-specific exploration interactions across LUNA, VEGA, CYG, ORION, TAU, SIRIUS and PROX.
- Discovery Field Notes and destination-specific classifications after completion.
- Arrival-to-exploration handoff and discovery completion handoff without adding a second navigation or persistence authority.
- Exploration-aware navigation markers and Star Atlas constellation progress / destination handoff.
- Destination Landmark Guide with explicit natural-versus-artificial landmark semantics.

### Scenery-first mobile UI

- Compact Explore Hub that keeps the 3D scene primary instead of leaving multiple exploration panels permanently expanded.
- Single mobile Explore entry with on-demand panes and mutually exclusive content.
- Exploration Focus Tray for task interactions while preserving most of the portrait viewport for the destination scene.
- Desktop readability scaling without changing the mobile-first rendering model.

### Journey presentation

- Destination-aware Journey Atmosphere.
- Route-specific Transit Corridor Vistas for the existing direct corridor network.
- Progressive Approach Vista treatment before the authoritative destination scene takes over.
- Warp-threshold entry / exit presentation and corridor landmark flybys.
- No replacement of the approved route graph, phase timing, real-direction turning, Hermite arrival or core camera authority.

### Continuity and reliability

- Reload World Continuity restores the latest strictly valid completed destination through existing core `WarpSim` authority.
- Route-topology validation rejects malformed or impossible persisted journey history before restore.
- Seamless reload handoff avoids exposing a false SOL frame while a valid destination restore is pending.
- Travel Journal and Star Atlas share discovery state without duplicating persistence authority.

### Capture value

- Destination Photo Mode remains available from safe final exploration.
- High-quality capture temporarily switches to the existing High renderer tier, waits for real rendered frames, exports the higher-resolution WebGL backing buffer, then restores the exact previous quality mode.
- Final production-WebGL evidence at 390×844 produced a 624×1350 PNG; 360×800 produced a 576×1280 PNG while CSS viewport geometry remained unchanged.

## Product invariants retained

- Star-map planning → real 3D direction turning → acceleration → warp entry → warp cruise → warp exit → continuous deceleration / approach → destination arrival → exploration.
- Existing eight-system coordinates and 6.0 LY Dijkstra route graph remain authoritative.
- Simulation timing is not altered to buy performance.
- Mobile portrait and smooth-motion priority remain intact.
- Zero-backend static architecture, pinned Three.js `0.185.1`, offline-relaunch path and WebGL recovery remain in place.
